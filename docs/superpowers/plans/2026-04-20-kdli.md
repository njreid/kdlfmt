**Goal:** Build `kdli` — a KDL Language Server that provides formatting (via `kdlfmt-core`), KSLv2 schema-aware diagnostics + completion + hover + code actions (via `ksl2rs`), and a filesystem-based schema discovery model (sibling → pragma → `~/.config/kdl/registry/`).

**Blocked by:** Plan A (`kdlfmt-core` 0.2.0 shipped) + Plan B (`ksl2rs` 0.2.0 with fork pin shipped). Both must be merged + tagged before Batch 0 starts.

**Spec reference:** `docs/superpowers/specs/2026-04-20-kdli-lsp/` (umbrella + 10 section files). The interface-lock in `07-interface-lock.md` is the authoritative signature reference for every module the plan creates.

//! In-memory filesystem for unit tests. Implements `FsSnapshot`.

use std::collections::HashMap;
use std::io;
use std::path::{Path, PathBuf};
use std::sync::RwLock;

use crate::interfaces::FsSnapshot;

pub struct MemFs {
    files: RwLock<HashMap<PathBuf, String>>,
}

impl MemFs {
    pub fn new() -> Self {
        Self { files: RwLock::new(HashMap::new()) }
    }

    pub fn from_pairs(pairs: &[(&str, &str)]) -> Self {
        let fs = Self::new();
        for (path, content) in pairs {
            fs.write(PathBuf::from(path), content.to_string());
        }
        fs
    }

    pub fn write(&self, path: PathBuf, content: String) {
        self.files.write().unwrap().insert(path, content);
    }
}

impl FsSnapshot for MemFs {
    fn read(&self, path: &Path) -> io::Result<String> {
        self.files
            .read()
            .unwrap()
            .get(path)
            .cloned()
            .ok_or_else(|| io::Error::new(io::ErrorKind::NotFound, format!("not found: {path:?}")))
    }

    fn exists(&self, path: &Path) -> bool {
        self.files.read().unwrap().contains_key(path)
    }

    fn read_dir(&self, path: &Path) -> io::Result<Vec<PathBuf>> {
        let mut out = Vec::new();
        let files = self.files.read().unwrap();
        for p in files.keys() {
            if let Some(parent) = p.parent() {
                if parent == path {
                    out.push(p.clone());
                }
            }
        }
        Ok(out)
    }

    fn canonicalize(&self, path: &Path) -> io::Result<PathBuf> {
        // MemFs has no symlinks; canonical is literal.
        Ok(path.to_path_buf())
    }
}

- [ ] **Step 4: Implement `discovery.rs`**

`kdli-core/src/discovery.rs`:

```rust
//! Schema discovery for .kdl files. Resolves a file to its schema via:
//! 1) Sibling <name>.ksl
//! 2) Pragma (/- ksl-schema <name> → registry/<name>.ksl)
//! 3) Registry unique match via top-level `match {}` globs
//! 4) Registry ambiguous match (surfaced to caller)
//! 5) None
//!
//! See docs/superpowers/specs/2026-04-20-kdli-lsp/02-schema-discovery.md

use std::path::{Path, PathBuf};
use std::sync::Arc;

use globset::{Glob, GlobSet, GlobSetBuilder};

use crate::interfaces::{FsSnapshot, SchemaResolution};

pub struct Resolver {
    home: PathBuf,
    registry_dir: PathBuf,
    fs: Arc<dyn FsSnapshot>,
}

impl Resolver {
    pub fn new(home: PathBuf, registry_dir: PathBuf, fs: Arc<dyn FsSnapshot>) -> Self {
        Self { home, registry_dir, fs }
    }

    pub fn from_env() -> Self {
        let home = std::env::var_os("HOME")
            .map(PathBuf::from)
            .unwrap_or_else(|| PathBuf::from("/"));
        let registry_dir = std::env::var_os("XDG_CONFIG_HOME")
            .map(PathBuf::from)
            .unwrap_or_else(|| home.join(".config"))
            .join("kdl")
            .join("registry");
        Self::new(home, registry_dir, Arc::new(crate::test_support::MemFs::new()))
        // NOTE: `from_env` is only used in tests / CLI smoke; real kdli-server
        // constructs Resolver::new with RealFs from its own module.
    }

    pub fn resolve(&self, kdl_file: &Path, pragma_name: Option<&str>) -> SchemaResolution {
        // Rule 1: sibling
        if let Some(stem) = kdl_file.file_stem() {
            let mut sibling = kdl_file.to_path_buf();
            sibling.set_file_name(format!("{}.ksl", stem.to_string_lossy()));
            if self.fs.exists(&sibling) {
                return SchemaResolution::Sibling { schema_path: sibling };
            }
        }

        // Rule 2: pragma
        if let Some(name) = pragma_name {
            let schema_path = self.registry_dir.join(format!("{name}.ksl"));
            return if self.fs.exists(&schema_path) {
                SchemaResolution::Pragma {
                    schema_name: name.to_string(),
                    schema_path,
                }
            } else {
                SchemaResolution::PragmaMissing { schema_name: name.to_string() }
            };
        }

        // Rule 3/4: registry
        let matches = self.match_registry(kdl_file);
        match matches.len() {
            0 => SchemaResolution::None,
            1 => {
                let (name, path) = matches.into_iter().next().unwrap();
                SchemaResolution::RegistryUnique {
                    schema_name: name,
                    schema_path: path,
                }
            }
            _ => SchemaResolution::RegistryAmbiguous { candidates: matches },
        }
    }

    fn match_registry(&self, kdl_file: &Path) -> Vec<(String, PathBuf)> {
        let canonical = match self.fs.canonicalize(kdl_file) {
            Ok(c) => c,
            Err(_) => kdl_file.to_path_buf(),
        };
        let Ok(entries) = self.fs.read_dir(&self.registry_dir) else {
            return Vec::new();
        };

        let mut matches = Vec::new();
        for entry in entries {
            if entry.extension().and_then(|e| e.to_str()) != Some("ksl") {
                continue;
            }
            let Ok(content) = self.fs.read(&entry) else { continue };
            let Some(globset) = parse_match_block(&content, &self.home) else { continue };
            if globset.is_match(&canonical) {
                if let Some(name) = entry.file_stem().and_then(|s| s.to_str()) {
                    matches.push((name.to_string(), entry));
                }
            }
        }
        matches
    }
}

fn parse_match_block(source: &str, home: &Path) -> Option<GlobSet> {
    let doc: kdl::KdlDocument = source.parse().ok()?;
    let match_node = doc.nodes().iter().find(|n| n.name().value() == "match")?;
    let children = match_node.children()?;

    let mut builder = GlobSetBuilder::new();
    let mut any = false;
    for child in children.nodes() {
        let pattern = child.name().value();
        let expanded = expand_path(pattern, home);
        if let Ok(g) = Glob::new(&expanded) {
            builder.add(g);
            any = true;
        }
    }
    if !any {
        return None;
    }
    builder.build().ok()
}

fn expand_path(pattern: &str, home: &Path) -> String {
    let tilde_expanded: std::borrow::Cow<'_, str> = if let Some(rest) = pattern.strip_prefix("~/")
    {
        format!("{}/{}", home.display(), rest).into()
    } else if pattern == "~" {
        home.display().to_string().into()
    } else {
        std::borrow::Cow::Borrowed(pattern)
    };
    shellexpand::env(&tilde_expanded)
        .map(std::borrow::Cow::into_owned)
        .unwrap_or_else(|_| tilde_expanded.into_owned())
}
```

//! Convert external diagnostic types (kdl::KdlError, ksl2rs::KslDiagnostic)
//! into the internal Diagnostic type defined in `interfaces`.

use crate::interfaces::{Diagnostic, LineIndex, Position, Range, Severity};

pub fn from_kdl_error(err: &kdl::KdlError, idx: &LineIndex) -> Vec<Diagnostic> {
    use miette::Diagnostic as _;

    let primary_range = err
        .labels()
        .and_then(|mut labels| labels.next())
        .map(|l| idx.span_to_range(*l.inner()))
        .unwrap_or(Range {
            start: Position { line: 0, character: 0 },
            end: Position { line: 0, character: 0 },
        });

    vec![Diagnostic {
        range: primary_range,
        severity: Severity::Error,
        code: err.code().map(|c| c.to_string()),
        source: "kdl",
        message: err.to_string(),
        related: Vec::new(),
    }]
}

pub fn from_ksl_diagnostic(d: &ksl2rs::KslDiagnostic, idx: &LineIndex) -> Diagnostic {
    let range = d
        .primary_span()
        .map(|span| idx.span_to_range(span))
        .unwrap_or(Range {
            start: Position { line: 0, character: 0 },
            end: Position { line: 0, character: 0 },
        });

    Diagnostic {
        range,
        severity: match d.severity {
            ksl2rs::Severity::Error => Severity::Error,
            ksl2rs::Severity::Warning => Severity::Warning,
            ksl2rs::Severity::Info => Severity::Information,
            ksl2rs::Severity::Hint => Severity::Hint,
        },
        code: Some(d.code.to_string()),
        source: "ksl",
        message: d.message.clone(),
        related: d
            .related
            .iter()
            .map(|r| crate::interfaces::RelatedInformation {
                location: crate::interfaces::Location {
                    uri: r.uri.clone(),
                    range: idx.span_to_range(r.span),
                },
                message: r.message.clone(),
            })
            .collect(),
    }
}
```

**Adapt field names** to ksl2rs's actual API. If `KslDiagnostic` uses different field names (e.g. `kind` instead of `code`, `primary_span` may not exist), adjust the mapping. The goal is: for every `KslDiagnostic` ksl2rs emits, produce a `Diagnostic` with matching severity + location + message + code.

use kdli_core::interfaces::{Range, TextEdit, Position};
use kdlfmt_core::{format_document, KdlFmtConfig, KdlVersion};

pub fn format_uri(
    source: &str,
    cfg: &KdlFmtConfig,
    version: KdlVersion,
) -> Result<Vec<TextEdit>, kdlfmt_core::FmtError> {
    let formatted = format_document(source, version, cfg)?;
    if formatted == source {
        return Ok(Vec::new());
    }
    // Single edit replacing entire document.
    let last_line = source.lines().count().saturating_sub(1) as u32;
    let last_col = source.lines().last().map(str::len).unwrap_or(0) as u32;
    Ok(vec![TextEdit {
        range: Range {
            start: Position { line: 0, character: 0 },
            end: Position { line: last_line, character: last_col },
        },
        new_text: formatted,
    }])
}
```
